# homebrew-tap

Homebrew formulae for [MikeDre](https://github.com/MikeDre) projects.

## Install

```bash
brew tap mikedre/tap
brew install squish
```

## Formulae

| Formula | Description |
|---------|-------------|
| [`squish`](https://github.com/MikeDre/squish) | Super fast local file optimisation: images, video, audio, and code |

Linux users: grab a prebuilt binary from the [squish releases page](https://github.com/MikeDre/squish/releases) or `cargo install squish-media-cli`.
